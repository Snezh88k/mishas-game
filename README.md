# Сайт-справочник по игре

Статический сайт без сборки и зависимостей: режимы, карты и сложность, башни, мобы.

## Как открыть

Откройте `index.html` в браузере (двойной клик). Сервер не нужен.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка страницы и разделы |
| `style.css` | Оформление (светлая и тёмная тема, телефон и ПК) |
| `app.js` | Рисует страницу из данных |
| `data.js` | Все цифры игры (режимы, карты, башни, мобы) |
| `tools/export-data.lua.txt` | Скрипт для Studio: выгружает свежие данные из игровых модулей |

## Как обновить цифры после правки баланса

1. Откройте place «Тест игрового режима» в Studio.
2. Вставьте `tools/export-data.lua.txt` в командную строку (Command Bar) и запустите.
3. Скопируйте строку JSON из Output в `data.js` после `window.GAME_DATA = `.
4. Верните вручную два поля, которых нет в игровых модулях: `"boss": true` у мобов
   Rook King, huge sphere и huge triangle и `"soon": true` у башни Bacon Comander
   (уберите его, когда башня появится в магазине лобби).

## Тексты, которые не берутся из игры

Подписи и пояснения лежат в `app.js` (раздел «Основы» — в `index.html`).
Если меняется правило игры (например, пауза между волнами или способность башни),
поправьте и цифру в данных, и текст.

## Публикация

Папку `website/` целиком можно выложить на любой статический хостинг
(GitHub Pages, Netlify, Cloudflare Pages и т. п.): сервер для сайта не нужен.
